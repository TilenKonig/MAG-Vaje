# PTS Vaja01: frontend, baza, backend

## 1. Obličje (frontend), 1 točka

- Delujoče obličje spletne aplikacije (npr. trgovina, stavnica, nepremičnine, to-do).
- Posredno ali neposredno omogoča pregled, vnos, urejanje in brisanje podatkov.

## 2. Podatkovna baza, 3 točke

- Načrtuj in vzpostavi bazo kot trajno shrambo funkcionalnosti.
- Vrsta baze: relacijska (MySQL/PostgreSQL), dokumentna (MongoDB) ali porazdeljena NewSQL (CockroachDB, **+1 točka**).
- Kje: lokalno (priporočen Docker) ali v oblaku (Supabase, Atlas, CockroachDB Cloud, +1 točka).
- Vsaj 2 povezani entiteti (pri MongoDB gnezdenje ali sklicevanje).
- Napolni z realističnimi podatki, približno **10.000 zapisov** (skripta, npr. Faker).

**Izbira:** CockroachDB, lokalno.

## 3. Uporaba baze in zaledje (backend), 1 točka

- Poveži bazo z obličjem, priporočljivo prek ločenega zaledja.
